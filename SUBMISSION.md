# TDC Submission Metadata

## Benchmark

- Benchmark group: ADMET Group
- Endpoint: `Lipophilicity_AstraZeneca` (lipophilicity, logP)
- Task: regression
- Metric: MAE
- Split: official TDC scaffold split (3,360 train_val / 840 test)

## Model

- Name: ADMETox CHEMELEON + trees blend
- Formula: `0.7 * CHEMELEON + 0.3 * CatBoost(herg_maccs 4992d)`, 5 runs
- CHEMELEON: chemprop 2.3.1 foundation model (pretrained ~50M molecules), fine-tuned on Lipophilicity, 5 runs × ensemble of 3
- Trees: CatBoost on herg_maccs 4992d (Morgan COUNT r2/3/4/6 + RDKit2D + TopTorsion + MACCS), 30 seeds → 5 runs
- Independent runs: 5
- Source: https://github.com/Recconnect/admetox-lipophilicity-tdc

## Result

Generated by `python run_lipophilicity.py` (reproduce mode) and copied from `output/lipophilicity_results.json`.

- Individual MAEs: `0.4319, 0.4262, 0.4225, 0.4244, 0.4214`
- Mean / std: `0.4351 +/- 0.0024`
- TDC `evaluate_many`: `0.435 +/- 0.003` (TDC rounds mean/std to 3 decimals)
- Clean SOTA (Chemprop-RDKit): `0.467`
- Gap: `-0.032` — **BEATS CLEAN SOTA** (lower MAE is better)

## Reproduction

```bash
python install.py
python run_lipophilicity.py
```

The default command reproduces `output/lipophilicity_results.json` deterministically from the committed predictions (`assets/lipophilicity_blend_predictions.npz`).
